Key-Value Store Demo

Interactive demonstration of Key-Value store operations using ClientApi from zcm-spring-sdk-starter

Primitive Types

Get String
Primitive
Retrieve a KV entry value as UTF-8 string. Key may contain slashes (e.g., config/api.endpoint)
Get Integer
Primitive
Retrieve a KV entry value as integer
Get Boolean
Primitive
Retrieve a KV entry value as boolean
Get Bytes
Primitive
Retrieve a KV entry value as raw bytes (displayed as base64)

Collections

Get List
Collection
Retrieve a KV entry value as a list of strings (comma-separated or structured list)
Get Map
Collection
Get all KV entries under a prefix as a flat map
Get Structured List
Collection
Get a structured list stored under a prefix as a list of maps

Utilities

List Keys
Utility
List only key paths (not full entries) under a prefix for a service
Check Exists
Utility
Check if a KV entry exists
